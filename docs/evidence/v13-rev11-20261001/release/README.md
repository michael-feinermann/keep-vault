# REV11 macOS Build 15: Prüfnachweise, keine Releasefreigabe

Diese Dateien sind unveränderte Kopien ausgewählter öffentlicher Ergebnisdateien für den gebauten Quellstand `b41144e191d743aa4474cb3a9fe1e5c1c7c567ba`. `inventory.json` bindet jede Kopie per SHA-256 an ihren lokalen Ursprungsbeleg. Die vollständigen Rohbelege verbleiben im dort genannten Arbeitsverzeichnis.

Der ursprüngliche Builder bestand 265 Gruppen und sechs gezielte Wiederholungen. Er endete anschließend wegen der fehlenden konfigurierten Leistungsreferenz mit Exit 2. Der separat wiederhergestellte verwaltete Testharness stimmt in 113 von 114 inventarisierten Eingaben überein; ausschließlich die Test-DLL ist neu. Dieser ergänzende Lauf wird nicht als Fortsetzung desselben ursprünglichen Prozesses dargestellt.

Beide ergänzenden Ciphermessungen scheiterten an der bisherigen Vergleichsgrenze. Die kontrollierte zweite Messung verwendet die vollständige bestandene Referenz vom 29. September mit derselben achtstufigen Paranoia-Kaskade. Die vier unabhängig ausgeführten Entropie-, MAC- und Paranoia-End-to-End-Gruppen bestanden. Ursache und Abschluss des Leistungsgates bleiben offen. Die frühere Phase 12 erfüllt nach der späteren Ciphermessung nicht den Vertrag eines letzten abschließenden funktionalen Laufs.

Installation, Apple-Signaturen, Notarisierung, Stapling, Gatekeeper, beide Architekturpfade der hybriden Paketprüfung und der kleine unverschlüsselte GUI-Rundlauf sind mit ihrem jeweiligen Umfang belegt. Die vollständige reale GUI-Abnahme ist offen. Es wird keine abgeschlossene Veröffentlichung oder absolute Sicherheitsgarantie behauptet.
