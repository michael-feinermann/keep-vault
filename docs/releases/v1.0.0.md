## Deutsch

Erste gemeinsame Veroeffentlichung fuer Windows und macOS. Beide Fassungen teilen den Kryptografiekern und das Containerformat v7.

Installationsanleitung: siehe README im Repository.

Jedes Paket traegt zusaetzlich zur Plattformsignatur eine unabhaengige duale Signatur aus RSA-PSS/SHA-512 und ML-DSA-87 (FIPS 204). Die .sha3-, .skein- und .khsig-Dateien gehoeren zum Paket und duerfen nicht getrennt werden.

macOS: die Dateien 'Keep Vault.app.launcher.*' muessen neben der App bleiben; der Launcher prueft bei jedem Start seine eigene duale Signatur.

Die macOS-Fassung ist noch nicht notarisiert.

---

## English

First joint release for Windows and macOS. Both editions share the cryptographic core and container format v7.

Installation instructions: see the repository README.

In addition to the platform signature, every package carries an independent dual signature of RSA-PSS/SHA-512 and ML-DSA-87 (FIPS 204). The .sha3, .skein and .khsig files belong to the package and must not be separated.

macOS: the files 'Keep Vault.app.launcher.*' must remain beside the app; the launcher checks its own dual signature on every start.

The macOS version is not yet notarized.
