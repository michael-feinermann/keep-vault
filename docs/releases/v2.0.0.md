## Deutsch

Containerformat **v8**. Mit v7 erzeugte Archive lassen sich mit dieser Fassung **nicht mehr oeffnen** — es gibt bewusst keinen Lesepfad fuer das alte Format.

**Neue Standardverschluesselung: Threefish-1024 ueber Kalyna-512/512.**
Zwei Schichten mit getrennten Schluesseln und getrennten Nonces. Argon2id
liefert 384 Byte: die ersten 64 fuer die innere Kalyna-Schicht, die naechsten
128 fuer die aeussere Threefish-Schicht, die restlichen 192 sind die beiden
MAC-Schluessel. Die Nonce ist ebenso 192 Byte lang und ebenso geteilt; dafuer
gibt es einen dritten Entropiepool.

Wer nur die aeussere Schicht bricht, haelt Kalyna-Chiffrat in den Haenden —
nicht den Klartext und nicht die Struktur des Archivs. Ein automatisierter Test
weist das nach. Kalyna-512/512 und Threefish-1024 stehen einzeln weiterhin zur
Wahl.

**Das macOS-Paket enthaelt beide Anwendungen**: Keep Vault und den
eigenstaendigen QR-Scanner fuer die gedruckten Schluesselzettel. Keep Vault
selbst fordert keinerlei Kamerazugriff an und deklariert keine
Hardwareberechtigung.

Die Dateien 'Keep Vault.app.launcher.*' muessen neben der App bleiben; der
Launcher prueft bei jedem Start seine eigene duale Signatur.

### Windows

**Dieses Release enthaelt kein Windows-Paket.** Der Windows-Quellcode ist auf
v8 umgestellt und liegt im Repository, aber die WPF-Anwendung laesst sich nur
unter Windows bauen. Ein v7-Build mitzuliefern haette genau die
Inkompatibilitaet erzeugt, die v8 vermeiden soll: er koennte die Archive dieser
Fassung nicht oeffnen. Das Windows-Paket folgt, sobald es auf einem
Windows-Rechner gebaut ist.

Installationsanleitung: siehe README im Repository.

Die macOS-Fassung ist nicht notarisiert.

## English

Container format v8. Archives created with v7 can no longer be opened by this version; there is deliberately no reader for the old format.

New default encryption: Threefish-1024 over Kalyna-512/512.
Two layers with separate keys and separate nonces. Argon2id supplies 384 bytes:
the first 64 for the inner Kalyna layer, the next 128 for the outer Threefish
layer, and the remaining 192 for the two MAC keys. The nonce is likewise
192 bytes long and divided in the same way; a third entropy pool supplies it.

Breaking only the outer layer leaves Kalyna ciphertext, neither plaintext
nor the archive structure. An automated test demonstrates this. Kalyna-512/512
and Threefish-1024 remain individually selectable.

The macOS package contains both applications: Keep Vault and the standalone
QR scanner for the printed key sheets. Keep Vault itself requests no camera
access and declares no hardware capability.

The files 'Keep Vault.app.launcher.*' must remain beside the app; the launcher
checks its own dual signature on every start.

### Windows

This release contains no Windows package. The Windows source has been moved
to v8 and is in the repository, but the WPF application can only be built on
Windows. Including a v7 build would have caused exactly the incompatibility
v8 is intended to avoid: it could not open this version's archives. The Windows
package will follow once it has been built on a Windows computer.

Installation instructions: see the repository README.

The macOS version is not notarized.
