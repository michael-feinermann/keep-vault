# Windows reference typography

The three unmodified Inter TrueType files are the exact assets embedded in
`Avalonia.Fonts.Inter` 12.1.1, which is pinned by the macOS reference application.
They are embedded as WPF resources so the Windows interface uses the same fonts
without depending on fonts installed on the user's computer.

Source package: https://www.nuget.org/packages/Avalonia.Fonts.Inter/12.1.1

Avalonia source revision: `e33eaed9c106846b200680751022385d9cc5dc6f`.

Font project and license: https://github.com/rsms/inter/blob/master/LICENSE.txt

The SIL Open Font License 1.1 is included in `OFL.txt` and embedded in the app.
